Avatar

A visual representation of a user or entity, shown as a photo or a monogram of their initials.

Features

  • Composable Avatar, Image, and Text parts
  • Circle and rounded-square shapes at four named sizes
  • Automatic image loading with a Text monogram fallback
  • Primary, subtle, and 15 categorical figure emphases
  • AvatarButton for accessible interactive avatar controls

Customization

Use Image native image props for responsive image sources. Choose a deterministic figure0 through figure14 emphasis in lists that categorize multiple entities.

Accessibility

  • Give Image meaningful alt text when the image conveys an identity.
  • Text remains available to assistive technology when no image loads.
  • Use alt="" or aria-hidden when an avatar is purely decorative.
  • AvatarButton requires aria-label or aria-labelledby.
  • AvatarButton supports keyboard activation and exposes the standard focus-visible state.

Best Practices

  • Use Avatar for informational identity; use AvatarButton only when the avatar is independently actionable.
  • Use circle for people and square for businesses, workspaces, and accounts.
  • Keep monograms to one or two uppercase characters.
  • Use the same figure* emphasis for the same entity wherever it appears.

Troubleshooting

  • If an image is unavailable because of a bad URL or CORS policy, Text remains visible.
  • Long Text content is clipped to the avatar shape; provide a one- or two-character monogram.
  • Figure colors repeat after 15 values; assign a deterministic figure emphasis in the consuming application.
