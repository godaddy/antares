Gauge Chart

GaugeChart shows one value on a known scale as a semicircle arc, in continuous or segmented mode.

Troubleshooting

Gauge Not Sizing Correctly

The gauge fills its parent's width and scales its text with it. Constrain the parent or set a maxWidth:

Value Out of Range

Values outside the scale are clamped. Continuous mode uses 0–100 and segmented mode uses 0 to segments. Normalize other measurements before passing them.

Props

Compose the center and range as optional direct children in either order. The description also describes the meter. Set valueLabel when the visible value isn't a plain number.

Optional center and range regions, in either order.

valuenumber—

Fill value — 0–100 for continuous, 0 to effective segment count when segmented. Clamped at runtime.

valueLabel?string—

Accessible text for the value, such as "3 of 5". Defaults to the numeric value.

segments?number—

Segment count for segmented mode; omit for continuous (0–100). When set, must be a finite positive integer or the component throws.

Font size of the center value. Use 'value' for a numeric or percentage value (larger type) and 'text' for a short descriptive string (smaller type).
