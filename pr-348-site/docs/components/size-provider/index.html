SizeProvider

Wrapperless size defaults for participating typography and controls.

Features

  • Provides sm, md, or lg through React context, including portals.
  • Explicit child sizes win. Nested providers inherit when size is omitted.
  • Adds no DOM wrapper and cannot style bare text.
  • Participating components: Text, Detail, Heading, Label, Button and its presets, TextField, TextLockup, and Modal. Other components have not adopted coordinated sizing.
  • Modal starts its own md scope. TextLockup coordinates named text without resizing controls.
  • Box, Flex, and Grid pass context through; their explicit spacing keeps its usual meaning.
