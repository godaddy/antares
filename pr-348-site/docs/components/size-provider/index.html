SizeProvider

Sizes a section, so the text, controls, and default spacing inside it follow one size.

Features

  • sm, md, or lg for everything inside: text, controls, and default spacing.
  • The nearest scope wins, and nested scopes replace the size rather than compounding it.
  • A component's own size prop wins for that component only.
  • Overlays opened inside, such as Modal and Select options, open at the scope's size even though they render in a portal.
  • Renders no element, so it never affects layout. Only Antares components follow it; plain HTML keeps its own typography, so put copy in Text.
  • Without any scope, components use md.
  • Adopted so far by Text, Detail, Heading, Label, Button, TextField, TextLockup, Select, Modal, Drawer, and Popover. Layout spacing props keep their meaning: gap="md" is the layout md gap in any scope.

Nested Scopes

The nearest scope wins. An inner scope replaces the outer size rather than scaling it, so an sm section inside an lg page matches sm anywhere else.
