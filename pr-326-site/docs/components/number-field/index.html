NumberField

NumberField is a composed numeric input with min/max/step and optional increment/decrement stepper buttons. Use it in forms for quantities, amounts, or percentages.

Features

  • Composable interior: Pass Label, Text slot="description", and FieldError; the field adds a Group of stepper Buttons around the Input, keeping the order you wrote. Write a bare Input for a plain numeric input, or a Group of your own to change the steppers
  • Steppers: Empty slot="decrement" / slot="increment" buttons get icons and variant="control" from context. Omit steppers for a plain numeric input
  • Value scale: minValue, maxValue, step, and formatOptions configure the numeric behavior
  • Controlled or uncontrolled: Use value and onChange for controlled state, or defaultValue for uncontrolled
  • Validation states: Use isInvalid with a FieldError and isDisabled for validation and disabled state

Value Scale

Use minValue, maxValue, and step to set the allowed values. Steps are calculated from the minimum value.

Steps are from the minimum: minValue={2}, step={3} gives 2, 5, 8, 11, …

Format options (numbering system)

By default, NumberField displays the value using the numbering system for the user's locale. Use the formatOptions prop to override the numbering system by setting the Unicode numbering system locale extension.

By default, NumberField uses the user's locale. Use formatOptions to override with a Unicode numbering system locale extension (e.g. nu-deva).
