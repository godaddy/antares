Popover

The Popover component is an overlay element positioned relative to a trigger element.

PopoverTrigger wraps a trigger button and a <Popover>, handling open state and positioning automatically. Based on RAC DialogTrigger. To anchor a popover to an element it doesn't wrap, pass triggerRef instead.

Installation

Examples

Default

Use it with <PopoverTrigger>, which wraps both the popover content and an interactive trigger element (for example, a Button).

Custom Anchor

To position a popover relative to a different element than its trigger, use the triggerRef and isOpen props instead of <PopoverTrigger>. onOpenChange is called when the user opens or closes the popover.

Popover will be positioned relative to me

Title and Close Button

Add a Heading slot="title" and a CloseButton for a titled, dismissible popover. The heading also gives the dialog its accessible name.

Accessibility

Keyboard

KeyAction
Enter/SpaceOpens the popover from its trigger
EscapeCloses the popover

ARIA

  • role="dialog" is applied automatically by the underlying React Aria Dialog
  • A Heading slot="title" labels the dialog via aria-labelledby. Without one, a popover inside a PopoverTrigger falls back to being labelled by its trigger; standing alone with triggerRef it needs an explicit aria-label

Best Practices

  • Pass an aria-label when anchoring with triggerRef instead of wrapping a PopoverTrigger, since there is no trigger to borrow the name from.
  • Popover width is determined by its content, and it's recommended to keep it under 400px.

Whether the popover is non-modal, i.e. elements outside the popover may be interacted with by assistive technologies.

Most popovers should not use this option. When set to true, an alternative way to close the popover with a keyboard must be provided.

When user interacts with the argument element outside of the popover ref, return true if onClose should be called. This gives you a chance to filter out interaction with elements that should not dismiss the popover. By default, onClose will always be called on interaction outside the popover ref.
