`PopoverTrigger` wraps a trigger button and a `<Popover>`, handling open state and positioning automatically.
Based on RAC `DialogTrigger`. To anchor a popover to an element it doesn't wrap, pass `triggerRef` instead.

## Installation

```bash
npm install --save @godaddy/antares
```

## Accessibility

### Keyboard

| Key           | Action                             |
| ------------- | ---------------------------------- |
| `Enter/Space` | Opens the popover from its trigger |
| `Escape`      | Closes the popover                 |

### ARIA

- `role="dialog"` is applied automatically by the underlying React Aria `Dialog`
- A `Heading slot="title"` labels the dialog via `aria-labelledby`; otherwise pass `aria-label`
- The arrow is `aria-hidden`

## Best Practices

- Provide a `Heading slot="title"` or an `aria-label` so the dialog has an accessible name.
- Popover width is determined by its content, and it's recommended to keep it under 400px.

## Props

```tsx
<PopoverTrigger>
  <Button />
  <Popover>
    <Header>
      <Heading slot="title" />
      <CloseButton />
    </Header>
    <Content />
  </Popover>
</PopoverTrigger>
```
