## Features

- **Composable interior**: Compose `Label`, `Group`, `Input` or `TextArea`, `Text slot="description"`, and `FieldError`
- **Adornments**: Fixed text or icons before or after the input (e.g. `$`, `.00`, `px`) are composed inside `Group`, positioned by source order
- **Controlled or uncontrolled**: Use `value` and `onChange` for controlled state, or `defaultValue` for uncontrolled
- **Multiline**: Compose a `TextArea` instead of an `Input` for multiline entry
- **Validation states**: Use `isInvalid` with a `FieldError` and `isDisabled` for validation and disabled state

## Props

`children` is the interior. A composed `Group` inherits `size` and `isDisabled` from the field, so set
them on `TextField` and leave the interior to the markup.

```tsx
<TextField>
  <Label />
  <Group>
    <Select variant="control" />
    <Input /> {/* or <TextArea /> */}
    <Button variant="control" />
  </Group>
  <Text slot="description" />
  <FieldError />
</TextField>
```

### Adornments

Fixed text or an icon before or after the input is composed inside `Group`; position comes from
source order, not a prop.

```tsx
<TextField>
  <Label>Amount</Label>
  <Group>
    <Flex as="span" alignItems="center" inlinePaddingStart="md">$</Flex>
    <Input placeholder="0.00" />
    <Flex as="span" alignItems="center" inlinePaddingEnd="md">.00</Flex>
  </Group>
</TextField>
```

An interactive affix (a country-code `Select`, a "Verify" `Button`) uses `variant="control"` instead
of the `Flex` wrapper — see the Controls and icons example above.
