## Features

- **Composition**: Nest `Label`, `Group`, `Input` or `TextArea`, `Text slot="description"`, and `FieldError`. Size lives on `Group`. Placeholder lives on `Input` / `TextArea`.
- **Controlled or uncontrolled**: Use `value` and `onChange` for controlled state, or `defaultValue` for uncontrolled.
- **Validation states**: Use `isInvalid` with `FieldError` and `isDisabled` for validation and disabled state.
- **Required indicator**: `isRequired` sets `data-required` on the field; Field CSS draws the asterisk on the label.
