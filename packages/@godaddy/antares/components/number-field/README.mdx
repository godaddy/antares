## Features

- **Composable interior**: Compose `Label`, the control, `Text slot="description"`, and `FieldError`. Nothing is added for you, and what you write keeps the order you wrote it in
- **Steppers**: A stepper is a `Group` holding `Button slot="decrement"`, an `Input`, and `Button slot="increment"`. Left empty, each button takes its icon, `variant="control"`, and `size` from the field, so no icon imports are needed. Compose a bare `Input` instead for a plain numeric input
- **Value scale**: `minValue`, `maxValue`, `step`, and `formatOptions` configure the numeric behavior
- **Controlled or uncontrolled**: Use `value` and `onChange` for controlled state, or `defaultValue` for uncontrolled
- **Validation states**: Use `isInvalid` with a `FieldError` and `isDisabled` for validation and disabled state

## Props

```tsx
<NumberField>
  <Label />
  <Group>
    <Button slot="decrement" />
    <Input />
    <Button slot="increment" />
  </Group>
  {/* or a bare <Input /> for a plain numeric input */}
  <Text slot="description" />
  <FieldError />
</NumberField>
```
