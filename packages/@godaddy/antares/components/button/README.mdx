## Customization

Use `variant="ghost"` as an unstyled interactive wrapper when the consumer controls rounding. Compose it with `Box` to apply the desired shape:

```tsx
<Box as={Button} aria-label="Account menu" variant="ghost" rounding="full">
  <Avatar>
    <Text>UT</Text>
  </Avatar>
</Box>
```
