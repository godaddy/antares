Use the `LinkButton` component instead when you need navigation functionality with a button-like appearance.

Use the `CloseButton` preset to dismiss an overlay (such as a `Modal`). It defaults to `slot="close"`, so it picks up the overlay's close behavior with no wiring, and always renders an `x` icon with `aria-label="Close"`. For a labelled dismiss action (e.g. "Cancel"), use a raw `<Button slot="close">Cancel</Button>`.

Use `variant="control"` for a filled button that sits beside an Input inside a field Group. Use
`variant="trigger"` for the transparent, full-width field face used by Select and DatePicker.
These variants inherit the surrounding field's size unless `size` is set explicitly.
