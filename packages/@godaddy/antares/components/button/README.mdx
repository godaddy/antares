Buttons trigger actions. To navigate, use `LinkButton`; `isExternal` adds an icon and opens a new tab.
For selection, use `ChipGroup` for filters or `ToggleButtonGroup` for a set of options.

`CloseButton` dismisses an overlay: it defaults to `slot="close"` and renders an `x` icon labelled "Close".

Inside a field `Group`, `slot="control"` and `slot="trigger"` take their look and size from the field.
The `control` variant also works standalone; `trigger` is a field part only.
