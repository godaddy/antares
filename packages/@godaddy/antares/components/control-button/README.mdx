## Features

- Use for NumberField steppers, Select/DatePicker triggers, and in-group actions.
- Do not use `Button` for those slots; Field would restyle every page button if it merged RAC `ButtonContext`.

## Installation

```bash
npm install --save @godaddy/antares
```
