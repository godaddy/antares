## Examples

<Examples of={Stories.Examples} />

Carousel follows the current locale direction. An explicit `emblaOptions.direction` also sets the
slide layout direction, which is useful when embedding a carousel in a differently directed region.

With `prefers-reduced-motion: reduce`, navigation and drag release settle immediately on the selected
slide. Dragging still follows the pointer, and selection, controls and announcements remain available.
