## Customization

`label` and the visible value can be controlled independently:

- Visible value output is hidden by default. Omitted, `null`, and `false` values for `valueLabel` hide it.
- Pass `valueLabel={true}` to show the formatted value, a React node for static content, or a render function for content derived from progress state.
- Without a `label` or `valueLabel`, only the track is shown. A value label can also appear without a visible label.
- Use `aria-label` or `aria-labelledby` to provide an accessible name when there is no visible label.

Hiding visible value text does not remove `aria-valuenow` or the formatted `aria-valuetext`.
Use `valueLabel` for custom value text.

To retain percentage text from earlier versions, add `valueLabel={true}` to existing progress bars.

## Accessibility

### ARIA Support

- `role="progressbar"` on the container
- `aria-valuenow` is omitted while indeterminate; otherwise it reflects the current value
- `aria-valuemin` and `aria-valuemax` define the range (default `0`–`100`)
- `aria-valuetext` and visible value text are omitted while indeterminate; otherwise `aria-valuetext` provides a formatted string (e.g. `"60%"`)
- `aria-labelledby` associates the visible label when the `label` prop is provided
