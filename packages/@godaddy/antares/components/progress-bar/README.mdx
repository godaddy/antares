## Customization

Use `Box slot="value"` for formatted or custom content, or `Text slot="value"` for typography controls.
The root's children render function provides progress state. Customize layout and styling with
Grid props, `className`, and `style`.

## Accessibility

- Provide `Label`, `aria-label`, or `aria-labelledby` for the accessible name.
- Progress remains accessible without a visible value. Use `valueLabel` to customize its text; indeterminate progress omits the value.
- `Text slot="description"` is associated automatically, preserving external `aria-describedby` references.

## Props

```tsx
<ProgressBar>
  <Label />
  <Box slot="value" />
  <Box slot="track" />
  <Text slot="description" />
  {/* ... */}
</ProgressBar>
```
