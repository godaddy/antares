## Customization

Compose `Label`, `Box` with `slot="track"`, an optional value slot, and `Text` with `slot="description"`.

Use `Box` with `slot="value"` for formatted text, or supply custom children. Use `Text` with the same
slot for typography props and the root's children render function for state-based content.

Set `valueLabel` to customize accessible value text. Omit the value slot to hide visible output;
empty and indeterminate values collapse automatically. Customize layout and styling with the
root's Grid props, `className`, and `style`.

## Accessibility

- The root has `role="progressbar"` and a range defined by `minValue` and `maxValue`, defaulting to 0 and 100.
- `Label` supplies the accessible name. When omitted, provide `aria-label` or `aria-labelledby`.
- Determinate progress exposes `aria-valuenow` and formatted `aria-valuetext`, even without a visible value slot.
- Indeterminate progress omits `aria-valuenow`, `aria-valuetext`, and visible value output.
- Mounted descriptions are associated automatically, including custom IDs. External `aria-describedby` references are preserved.
- Description association is established on mounting. Server-rendered descriptions are associated when the component hydrates.
- Reduced motion stops the indeterminate sweep while retaining a visible indicator. RTL and forced colors are supported.

## Props

```tsx
<ProgressBar>
  <Label />
  <Box slot="value" />
  <Box slot="track" />
  <Text slot="description" />
  {/* ... */}
</ProgressBar>
```
