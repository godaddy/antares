## Customization

Compose only the parts you need:

- `Label` provides a visible, associated name.
- `ProgressBarValue` shows the formatted value by default. Its children accept static content or a render function receiving `percentage`, `valueText`, and `isIndeterminate`.
- `ProgressBarTrack` renders the fill and inherits the root's size and status.
- `Text slot="description"` provides helper text with an automatic accessible association.

Omitting `ProgressBarValue` hides visible value output while preserving accessible progress. Omit both label and value for a compact track-only layout. Parts use named grid areas, so direct children and fragments can be written in any order. Use `display: contents` on a wrapper when its parts should participate in the root's grid, or override the root's Grid layout props for custom placement.

Custom visual value content does not change `aria-valuetext`. The root's `valueLabel` accepts a string for accessible value text and the default output of `ProgressBarValue`; it does not add a visible value by itself.

### Migration

Replace root `label` with `Label` and `helperText` with `Text slot="description"`. Add `ProgressBarTrack` explicitly, and add `ProgressBarValue` to retain visible percentage text:

```tsx
<ProgressBar value={60}>
  <Label>Uploading</Label>
  <ProgressBarValue />
  <ProgressBarTrack />
  <Text slot="description">3 of 5 files uploaded</Text>
</ProgressBar>
```

## Accessibility

- The root has `role="progressbar"` and a range defined by `minValue` and `maxValue`, defaulting to 0 and 100.
- `Label` supplies the accessible name. When omitted, provide `aria-label` or `aria-labelledby`.
- Determinate progress exposes `aria-valuenow` and formatted `aria-valuetext`, even without `ProgressBarValue`.
- Indeterminate progress omits `aria-valuenow`, `aria-valuetext`, and visible value output.
- Mounted descriptions are associated automatically, including custom IDs. External `aria-describedby` references are preserved.
- Description association is established on mounting. Server-rendered descriptions are associated when the component hydrates.
- Reduced motion stops the indeterminate sweep while retaining a visible indicator. RTL and forced colors are supported.
