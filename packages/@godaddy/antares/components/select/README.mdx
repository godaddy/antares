## Features

- **Composable interior**: Compose `Label`, `Group`, `Button`, `SelectValue`, `Popover`, `Content`, `ListBox`, `SelectItem`, `Text`, and `FieldError`, or a function when the interior needs the Select state
- **Single or multiple selection**: Set `selectionMode="multiple"` to allow multiple values
- **Controlled or uncontrolled**: Use `value` and `onChange` for controlled state, or `defaultValue` for uncontrolled
- **Validation states**: Use `isInvalid` with a `FieldError` and `isDisabled` for validation and disabled state
- **Form integration**: Set `name` and the value submits as part of a native `<form>` (multiple values submit as repeated entries)
- **React Aria integration**: Built on React Aria Select for accessibility, keyboard navigation, and typeahead

## Props

`children` is the interior: `Label`, `Group`, `Button` (`SelectValue` plus an `Icon`), `Popover` with
`Content` and `ListBox` holding `SelectItem`s, `Text slot="description"`, and `FieldError`. Or a
function returning that interior — use this when it needs the Select state: it receives `isOpen`,
`isInvalid`, and the rest of the render props.

```tsx
<Select>
  <Label />
  <Group>
    <Button variant="trigger">
      <SelectValue />
      <Icon icon="chevron-down" />
    </Button>
  </Group>
  <Text slot="description" />
  <FieldError />
  <Popover>
    <Content>
      <ListBox>
        <SelectItem />
      </ListBox>
    </Content>
  </Popover>
</Select>
```

Use `variant="control"` when Select shares a `Group` owned by another field, such as a currency Select
inside a TextField. This omits Select's own field shell and `Label` — a control-variant Select still
needs its own `aria-label`.

Option components may wrap `SelectItem`. Select passes unrecognized children through its `ListBox`,
whose collection builder resolves the wrapped items.
