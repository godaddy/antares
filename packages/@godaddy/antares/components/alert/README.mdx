## Features

- Seven emphasis categories with an optional composed icon
- Consumer-owned title, body, actions, and dismissal
- Native props on the outer surface and overridable presentation defaults for its children
- Container-based action reflow with logical layout for RTL

## Customization

Alert positions and styles its regions. Compose them as direct children, in any source order: an optional
`Icon slot="indicator"`, a `Content`, an optional `ButtonGroup`, and an optional `CloseButton`.

- Put `Heading slot="title"` and an unslotted `Text` body inside `Content`.
- Choose the glyph on the icon, for example `<Icon slot="indicator" icon="alert" />`. It is decorative and 26px by
  default; pass `width` and `height` to change it, or omit it when the message stands alone. Icons without
  `slot="indicator"` do not get these defaults.
- Pass `onPress` on `CloseButton` and hide the alert from the parent. Use `Button slot="close"` for a visible label.
- Extract regions into a component by returning them from a fragment. A wrapper element is not placed in the layout
  grid, so put custom layout inside `Content`.
- Props on a child win over Alert's defaults. Classes merge and local style properties win.
- Put `className`, `style`, `ref`, native attributes, and `data-emphasis` on Alert for the surface.
- Omitted regions collapse, and in narrow containers the actions stack under the content.

## Accessibility

### Keyboard

| Key | Action |
| --- | --- |
| `Tab` / `Shift + Tab` | Moves between controls in the consumer's source order |
| `Enter` / `Space` | Activates the focused button |

### Screen readers

The surface defaults to `role="alert"`, an assertive live region. Use `role="status"` for polite updates when appropriate.

Choose the `Heading` level for the surrounding page. The `title` slot styles the title but does not set `aria-labelledby` or `aria-describedby` on `Alert`. Add explicit labeling attributes when the surface needs an accessible name. `CloseButton` defaults to `aria-label="Close"`; set `aria-label` directly on that button for localization or more context.

The parent controls visibility and focus restoration after dismissal.

## Best Practices

- Explain what happened and how the user can respond.
- Reserve critical emphasis and assertive announcements for messages that warrant interruption.
- Prefer secondary or tertiary actions inside an alert.
- Keep interactive source order aligned with the reading order.
- Test long content, RTL, and enlarged text in narrow containers.

## Props

```tsx
<Alert>
  <Icon slot="indicator" icon="information" />
  <Content>
    <Heading slot="title" />
    <Text />
  </Content>
  <ButtonGroup />
  <CloseButton />
  {/* ... */}
</Alert>
```
