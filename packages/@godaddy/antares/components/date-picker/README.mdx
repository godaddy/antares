## Features

- Single-date and range selection, with a formatted trigger and responsive calendar
- Compose `Label`, `Button slot="trigger"`, a calendar, and optional description or error text
- `size` (`sm`, `md`, `lg`) applies to the field and calendar; omitted sizes follow the surrounding scope
- Customize the trigger with `formatOptions`, `placeholder`, or `DatePickerValue` / `DateRangePickerValue`
- Date bounds, unavailable dates, form validation, and keyboard navigation through React Aria

## Installation

```bash
npm install @godaddy/antares
```

## Working with dates

Values are `CalendarDate` objects. Import helpers from `@godaddy/antares/date`, which re-exports
[`@internationalized/date`](https://react-spectrum.adobe.com/internationalized/date/):

```tsx
import { parseDate } from '@godaddy/antares/date';

const date = parseDate('2024-03-15');
```

Use `<I18nProvider>` to set the locale for formatting and calendar navigation.

## Mobile

Below `40rem`, calendars open in a bottom drawer with continuous month scrolling. Use the month/year
controls to jump directly. Resizing changes the presentation on the next opening.

- `overlay="popover"` always uses the desktop presentation.
- `drawerProps` customizes the drawer, which defaults to `85dvh`; `popoverProps` customizes the popover.
- `pageCount` sets months per popover page: one for single dates and two for ranges by default.
- `commitBehavior` on `DateRangePickerCalendar` applies to both presentations.
- `shouldCloseOnSelect={false}` on the picker keeps the calendar open after selection.

```tsx
<DatePicker>
  <Label>Event date</Label>
  <Button slot="trigger" />
  <DatePickerCalendar drawerProps={{ maxSize: '90dvh' }} />
</DatePicker>
```

## Accessibility

- Label the picker; its calendar uses the same accessible name.
- Arrow keys move between dates; Page Up/Down moves between months. Scrolling preserves focus and selection.
- Escape or dismissal returns focus to the trigger. Escape cancels an unfinished range.
- Enlarged text remains readable, with horizontal scrolling inside the drawer when needed.
