## Features

- **Composable interior**: Pass `Label` and optional `Text` / `FieldError`; the field adds the trigger and the calendar popover, keeping the order you wrote. Write a `DatePickerControl` to set the label format, or a `Group`, `Button`, `DatePickerValue`, `Popover`, `Content`, and `Calendar` interior of your own to replace either part. `children` also accepts a function for picker state
- `DatePicker` (single) and `DateRangePicker` (range): a read-only formatted date label; the whole field opens a calendar popover
- Built on React Aria - native form integration, validation, focus management, and screen-reader support
- Label formatting via `formatOptions` / `placeholder` on `DatePickerControl` / `DateRangePickerControl`, or on `DatePickerValue` / `DateRangePickerValue` when composing
- `minValue` / `maxValue` bounds and `isDateUnavailable` per-day disabling

## Installation

```bash
npm install @godaddy/antares
```

## Working with dates

Values are `CalendarDate` objects. Import the date primitives you need from the `@godaddy/antares/date` subpath:

```tsx
import { parseDate } from '@godaddy/antares/date';
import { DatePicker, Label } from '@godaddy/antares';

function EventDatePicker() {
  return (
    <DatePicker defaultValue={parseDate('2024-03-15')}>
      <Label>Event date</Label>
    </DatePicker>
  );
}
```

Import date helpers from `@godaddy/antares/date` (a re-export of
[`@internationalized/date`](https://react-spectrum.adobe.com/internationalized/date/)).
Wrap the app in `<I18nProvider>` so formatting and the calendar follow the user's locale.
