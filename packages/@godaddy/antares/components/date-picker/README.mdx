## Features

- **Composable interior**: Compose `Label`, a `Button slot="trigger"`, `DatePickerCalendar`, and optional `Text` / `FieldError`. Nothing is added for you, and what you write keeps the order you wrote it in. `children` also accepts a function for picker state
- **Trigger and calendar**: An empty `Button slot="trigger"` renders a calendar icon and the formatted value from the field. `DatePickerCalendar` (and `DateRangePickerCalendar`) opens a responsive calendar: it takes `Calendar` props plus `popoverProps` and `drawerProps` for its overlay. Write `Popover`, `Content`, and `Calendar` yourself to replace the whole overlay
- **Sizes**: Each picker is a `SizeProvider`. `size` (`sm`, `md`, `lg`) sets its label, trigger, description, error, and the calendar it opens; without it, the picker follows the surrounding scope
- `DatePicker` (single) and `DateRangePicker` (range): a read-only formatted date label; the whole field opens a calendar
- Built on React Aria - native form integration, validation, focus management, and screen-reader support
- Label formatting via `formatOptions` / `placeholder` on the picker itself, or on `DatePickerValue` / `DateRangePickerValue` in a trigger you write
- `minValue` / `maxValue` bounds and `isDateUnavailable` per-day disabling

## Installation

```bash
npm install @godaddy/antares
```

## Working with dates

Values are `CalendarDate` objects. Import the date primitives you need from the `@godaddy/antares/date` subpath:

```tsx
import { parseDate } from '@godaddy/antares/date';
import { DatePicker, Label } from '@godaddy/antares';

function EventDatePicker() {
  return (
    <DatePicker defaultValue={parseDate('2024-03-15')}>
      <Label>Event date</Label>
    </DatePicker>
  );
}
```

Import date helpers from `@godaddy/antares/date` (a re-export of
[`@internationalized/date`](https://react-spectrum.adobe.com/internationalized/date/)).
Wrap the app in `<I18nProvider>` so formatting and the calendar follow the user's locale.

## Mobile

Below `40rem`, `DatePickerCalendar` and `DateRangePickerCalendar` open a bottom drawer with vertically
scrolling months. Scroll forward or backward, choose a month, or type a year to jump directly. The
initial month follows `focusedValue`, `defaultFocusedValue`, the selected date (range start), then today,
constrained by the date bounds.

The overlay keeps its container until it closes, including during resizing. Its next opening uses the
current viewport. An initially open server-rendered picker keeps its popover through hydration.

- Set `overlay="popover"` on the calendar to always use the desktop presentation.
- Use `drawerProps` for drawer presentation, such as `maxSize` or an accessible label. It defaults to
  `85dvh`. Open state stays on the picker; `popoverProps` configures the popover.
- `pageCount` applies to the popover. The drawer renders the months near the visible area as needed.
- A range is committed when both dates are chosen. Browsing or editing the header keeps the pending
  start date; dismissing the drawer cancels it and preserves the previous selection.
- `shouldCloseOnSelect={false}` on the picker keeps either presentation open after a selection.

```tsx
<DatePicker>
  <Label>Event date</Label>
  <Button slot="trigger" />
  <DatePickerCalendar drawerProps={{ maxSize: '90dvh' }} />
</DatePicker>
```

## Accessibility

The drawer has the same accessible name as the picker. Escape, an outside press, or the screen-reader
dismiss control closes it and returns focus to the trigger. Arrow keys and Page Up/Down retain React
Aria's calendar navigation. Scrolling does not move keyboard focus or change the selected value. Weekday labels shorten when the
calendar has limited space, including with enlarged text; their accessible names are preserved.


## Props

```tsx
<DatePicker>
  <Label />
  <Group>
    <Button slot="trigger">
      <DatePickerValue />
    </Button>
  </Group>
  <Text slot="description" />
  <Popover>
    <Content>
      <Calendar />
    </Content>
  </Popover>
  <FieldError />
</DatePicker>
```

```tsx
<DateRangePicker>
  <Label />
  <Group>

  </Group>
  <Text slot="description" />
  <Popover>
    <Content>
      <RangeCalendar />
    </Content>
  </Popover>
  <FieldError />
</DateRangePicker>
```
