## Features

- `DatePicker` (single) and `DateRangePicker` (range): a read-only formatted date label; the whole field opens a calendar popover
- Built on React Aria — native form integration, validation, focus management, and screen-reader support
- Consumer-controlled label formatting via `formatOptions` on `DatePickerValue` / `DateRangePickerValue`
- `minValue` / `maxValue` bounds and `isDateUnavailable` per-day disabling

## Installation

```bash
npm install @godaddy/antares
```

## Working with dates

Values are `CalendarDate` objects. Import the date primitives you need from the `@godaddy/antares/date` subpath:

```tsx
import { parseDate, today, getLocalTimeZone } from '@godaddy/antares/date';
import { Button, Calendar, Content, DatePicker, DatePickerValue, Group, Icon, Label, Popover } from '@godaddy/antares';

function EventDatePicker() {
  return (
    <DatePicker defaultValue={parseDate('2024-03-15')}>
      <Label>Event</Label>
      <Group alignItems="center">
        <Button variant="trigger">
          <Icon icon="calendar" />
          <DatePickerValue />
        </Button>
      </Group>
      <Popover hideArrow>
        <Content>
          <Calendar />
        </Content>
      </Popover>
    </DatePicker>
  );
}
```

`@godaddy/antares/date` re-exports [`@internationalized/date`](https://react-spectrum.adobe.com/internationalized/date/), the package behind these date primitives. Locale comes from a host `<I18nProvider>`. This version has no typed/segmented entry - selection is via the calendar.

## Customization

`children` is the interior: `Label`, `Group`, a trigger `Button` (an `Icon` plus `DatePickerValue` or
`DateRangePickerValue`), `Text slot="description"`, `FieldError`, `Popover`, `Content`, and `Calendar`
or `RangeCalendar`. Or a function returning that interior when it needs picker state (`isOpen`, …).

```tsx
<DatePicker>
  <Label />
  <Group>
    <Button variant="trigger">
      <Icon icon="calendar" />
      <DatePickerValue />
    </Button>
  </Group>
  <Text slot="description" />
  <FieldError />
  <Popover>
    <Content>
      <Calendar />
    </Content>
  </Popover>
</DatePicker>
```

`DatePickerValue` and `DateRangePickerValue` accept `formatOptions` (any `Intl.DateTimeFormatOptions`,
e.g. `{ dateStyle: 'short' }`) and `placeholder` for the empty-state text.

## Accessibility

- The whole field is a single focusable button; Enter/Space opens the popover
- Focus is trapped in the open popover and returns to the trigger on close
- Esc and outside-click dismiss the popover
- The calendar grid is fully keyboard navigable and screen-reader announced

## Best Practices

- Provide a `Label` (or `aria-label`) on every picker.
- For typed/keyboard-fast date entry far from today, use the calendar's month dropdown and year input.

## Troubleshooting

- Dates not localizing? Wrap the app in `<I18nProvider locale="…">`.
- Form value missing on submit? Pass a `name` — React Aria renders the hidden input.
