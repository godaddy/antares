An accessible dropdown menu built on React Aria. It supports grouping with optional
titles, multi-select checkbox items, leading icons, submenus, and two sizes. It
reuses Antares' `Popover` for the overlay and `Checkbox` indicator for selection.

## Features

- Grouping with an optional title via `MenuGroup`, plus `MenuSeparator` dividers
- Multi-select groups: set `selectionMode="multiple"` on a `MenuGroup` to render
  its items as checkboxes, while other groups stay plain action items
- Optional leading `icon` per item; links (`href`) and disabled items
- Submenus via `SubmenuTrigger`
- Two sizes (`sm`, `md`) that submenus inherit automatically
- Usable anchored to a trigger or standalone (e.g. inside a bottom-sheet `Drawer`)

## Customization

Selection is scoped per group. Give a `MenuGroup` `selectionMode="multiple"` to
turn its items into checkboxes; leave it off to keep plain action items - both
can coexist in one menu. Seed the initially checked items with
`defaultSelectedKeys` (uncontrolled) or drive them with `selectedKeys` +
`onSelectionChange` (controlled); keys match each `MenuItem`'s `id`. Menu-level
selection props are also supported for the simple whole-menu case.

`size` is set per `Menu` (`sm` / `md`). Submenus do not inherit it - set `size`
on each submenu `Menu` if you want a smaller nested menu. RAC state data
attributes (`data-hovered`, `data-focused`, `data-selected`, `data-disabled`,
and `aria-expanded` on the trigger) are available for styling via `className`.

## Accessibility

- **Space/Enter**: activate an item; **Escape**: close
- **Arrow Up/Down**: move between items; **Home/End**: first/last
- **Arrow Right/Left**: open/close a submenu
- **Type to select**: jump to a matching item (string labels are used as `textValue`)
- Multi-select items use RAC's `menuitemcheckbox` role; the checkbox indicator is
  decorative (`aria-hidden`) and the item owns interaction

## Best Practices

- Give each selectable `MenuItem` a stable `id`, and provide the `Menu` an
  `aria-label` when there is no visible label.
- Use a leading `icon` for recognition, not as the only label - keep a text label.
- Reserve checkbox groups for multi-select; use plain groups for one-shot actions.

## Troubleshooting

### Submenu not opening

```tsx
// ❌ Menu nested directly inside a MenuItem
<MenuItem id="share">
  Share
  <Menu>…</Menu>
</MenuItem>

// ✅ Wrap the item and its submenu in SubmenuTrigger
<SubmenuTrigger>
  <MenuItem id="share">Share</MenuItem>
  <Menu aria-label="Share">…</Menu>
</SubmenuTrigger>
```

### Every item shows a checkbox

`selectionMode="multiple"` on the `Menu` applies to all items. Scope it to a
`MenuGroup` instead so only that group renders checkboxes.
