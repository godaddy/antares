`Text` is body copy and `Detail` is supporting copy: captions, metadata, and hints.

## Features

- Without `size`, `Text` inherits every font property from what surrounds it: a
  [SizeScope](../size-scope/README.mdx), a control, or a named part. So
  `<Button><Text>Save</Text></Button>` looks exactly like `<Button>Save</Button>`.
- `Detail` applies the detail role at the size scope's tier.
- `size` picks a step on the component's own ramp (`xs` to `2xl`) and changes only the font size.
- `emphasis` picks a feedback color and changes only the color.
- For semantic emphasis, render `as="strong"` or `as="em"`.
