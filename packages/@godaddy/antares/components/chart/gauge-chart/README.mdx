## Props

```tsx
<GaugeChart value={3} segments={5} valueLabel="3 of 5" aria-label="Site health">
  <GaugeChartCenter>
    <Text slot="value" size="2xl">3/5</Text>
    <Text slot="description">Health score</Text>
  </GaugeChartCenter>
  <GaugeChartRange>
    <Text slot="min">0</Text>
    <Text slot="max">5</Text>
  </GaugeChartRange>
</GaugeChart>
```

Compose the optional center and range in either order. Use `Text` in the `value` and `description` slots. An explicit `Text size` overrides the responsive default. The chart links to the description using its existing ID or a generated one. Use `labelType="text"` for a smaller default and `valueLabel` for accessible value text.

Place slotted `Text` directly inside its region when mixing it with unslotted controls. Controls in either region remain clickable.

Continuous values are clamped to 0–100. Segmented values are clamped to 0–`segments`.
