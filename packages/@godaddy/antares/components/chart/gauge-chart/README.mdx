## Troubleshooting

### Gauge Not Sizing Correctly

The gauge fills its parent's width and scales its text with it. Constrain the parent or set a `maxWidth`:

```tsx
<GaugeChart value={50} aria-label="Progress" style={{ maxWidth: 200 }}>
  <GaugeChartCenter>
    <Text slot="value">50%</Text>
  </GaugeChartCenter>
</GaugeChart>
```

### Value Out of Range

Values outside the scale are clamped. Continuous mode uses 0–100 and segmented mode uses 0 to `segments`. Normalize other measurements before passing them.

## Props

```tsx
<GaugeChart value={3} segments={5}>
  <GaugeChartCenter>
    <Text slot="value" />
    <Text slot="description" />
  </GaugeChartCenter>
  <GaugeChartRange>
    <Text slot="min" />
    <Text slot="max" />
  </GaugeChartRange>
</GaugeChart>
```

Compose the center and range as optional direct children in either order. The description also describes the meter. Set `valueLabel` when the visible value isn't a plain number.
