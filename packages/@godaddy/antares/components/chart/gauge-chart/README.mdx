## Troubleshooting

### Gauge Not Sizing Correctly

The gauge fills its parent's width and scales its text with it. Constrain the parent or set a `maxWidth`:

```tsx
<GaugeChart value={50} aria-label="Progress" style={{ maxWidth: 200 }}>
  <GaugeChartCenter>
    <Text slot="value">50%</Text>
  </GaugeChartCenter>
</GaugeChart>
```

### Value Out of Range

Values outside the scale are clamped. Continuous mode uses 0–100 and segmented mode uses 0 to `segments`. Normalize other measurements before passing them.

## Props

```tsx
<GaugeChart value={3} segments={5} valueLabel="3 of 5" aria-label="Site health">
  <GaugeChartCenter>
    <Text slot="value" size="2xl">3/5</Text>
    <Text slot="description">Health score</Text>
  </GaugeChartCenter>
  <GaugeChartRange>
    <Text slot="min" />
    <Text slot="max" />
  </GaugeChartRange>
</GaugeChart>
```

Use `GaugeChartCenter` with `Text` in the `value` and `description` slots. The slots can appear in either order. An explicit `Text size` overrides the chart's responsive default.

Compose the center and range as optional direct children in either order. The description also describes the meter. Set `valueLabel` when the visible value isn't a plain number. `labelType="text"` makes the default value size smaller for short words. The arc carries the meter role so controls in the center stay accessible.
