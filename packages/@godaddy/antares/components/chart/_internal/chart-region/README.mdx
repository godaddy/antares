## For use with chart components (not exported)

Each public region defines its name, its public context, and its text slots once, then renders `ChartRegion`. The chart provides placement for each region through `ChartRegionsContext`.

```tsx
const centerRegion: ChartRegionDefinition = { name: 'center', context: CenterContext, slots: { value: styles.value } };

export function Center(props: CenterProps) {
  return <ChartRegion {...props} region={centerRegion} />;
}
```

Consumer props and context overrides apply over the region's defaults. The chart's placement class and slot props always apply, so overrides cannot break the chart layout.

Regions let pointer events pass through their empty space while keeping controls interactive.
