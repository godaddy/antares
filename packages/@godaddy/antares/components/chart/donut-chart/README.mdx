## Props

```tsx
<DonutChart data={[{ name: 'Online', value: 70 }, { name: 'In store', value: 30 }]} aria-label="Sales by channel">
  <DonutChartCenter>
    <Text slot="value" size="2xl">100%</Text>
    <Text slot="description">Total sales</Text>
  </DonutChartCenter>
  <ChartLegend />
</DonutChart>
```

Compose the optional center and legend in either order. Use `Text` in the `value` and `description` slots. An explicit `Text size` overrides the responsive default. The chart links to the mounted description using its `id`, or generates one when the slot has no `id`.
