## Props

```tsx
<DonutChart data={[{ name: 'Online', value: 70 }, { name: 'In store', value: 30 }]} aria-label="Sales by channel">
  <DonutChartCenter>
    <Text slot="value" size="2xl">100%</Text>
    <Text slot="description">Total sales</Text>
  </DonutChartCenter>
  <ChartLegend />
</DonutChart>
```

Use `DonutChartCenter` with `Text` in the `value` and `description` slots. The slots can appear in either order. An explicit `Text size` overrides the chart's responsive default.

Compose the center and legend as optional direct children in either order. The description also describes the ring. The ring, legend, and tooltip share the same slice colors. The built-in tooltip keeps percentage and value columns and groups adjacent small slices.
