## Features

- Independent sections with controlled or uncontrolled expansion.
- Composed headings, optional status icons, and flexible panel content.
- Persistent panel content when collapsed.
- Accessible keyboard interaction and button-to-panel relationships powered by React Aria Components.

## Installation

```bash

```

## Customization

Place a `Heading` containing `Button slot="trigger"` inside Collapsible, followed by CollapsiblePanel.
Add an `Icon slot="indicator"` inside the button for the expansion indicator. The panel accepts text,
links, forms, and other components.

Use `defaultExpanded` for initial expansion, or `isExpanded` with `onExpandedChange` for controlled
state. The callback receives a boolean. Use [Accordion](../accordion/README.mdx) to coordinate several
sections; in that composition, manage expansion through the group.

Use `className` and `style` to customize each component. Button supports string or state-based
`className` values. Components expose these data attributes for state-based styling:

- `Collapsible`: `data-expanded`, `data-disabled`, and `data-focus-visible-within`.
- Trigger `Button`: `data-hovered`, `data-pressed`, `data-focus-visible`, and `data-disabled`.
- `CollapsiblePanel`: `data-focus-visible-within`.

## Accessibility

Choose a Heading level that fits the page hierarchy and use descriptive trigger text. React Aria connects
the trigger and panel through `aria-expanded`, `aria-controls`, and `aria-labelledby`.

| Key | Action |
| --- | --- |
| `Tab` / `Shift + Tab` | Moves between available controls. |
| `Enter` / `Space` | Expands or collapses the focused section. |

Disabled triggers are excluded from the tab order. Collapsed panel content stays mounted but is
excluded from keyboard and accessibility navigation. Opening a panel keeps focus on its trigger.
If application logic closes a panel containing focus, move focus to a visible control.

Keep the indicator decorative with `aria-hidden="true"`. If an optional icon communicates status,
include equivalent text in the label. Place links, inputs, and additional buttons in the panel.
Use `role="region"` on CollapsiblePanel when its content warrants a named landmark.

## Best Practices

- Use descriptive section titles and keep essential information visible.
- Keep headings concise and avoid deeply nested sections.
- Put links, forms, and actions inside the panel.
- Open the panel before moving focus to an input that needs attention.

## Troubleshooting

### Controlled State Not Updating

Update `isExpanded` from `onExpandedChange`. Changing `defaultExpanded` after mounting does not
control expansion. Inside Accordion, update the group's `expandedKeys` instead.

### Trigger Not Expanding the Panel

Place `Button slot="trigger"` inside the section's Heading. A Button without that slot acts
independently and does not toggle the section.

### Input Values Persist After Closing

Panel content stays mounted when collapsed. Reset form state explicitly when the application requires it.
