Card is a layout surface. Default padding and gap are `lg`. `href` and `onPress` add a primary
action. `selection` adds a checkbox or radio; place `CardSelectionIndicator` yourself.

## Installation

```bash
npm install @godaddy/antares
```

## Accessibility

- Name a primary action with `aria-label` or `aria-labelledby`. The stretched control has no visible
  label of its own.
- Name selection separately with `selectionProps` when the Card also has a primary action.
- Nested buttons, links, labels, and fields keep their own behavior. Clicking body text activates
  the Card; dragging text selects it.
- `isDisabled` disables only the primary. `isSelectionDisabled` disables only selection. Radio
  read-only belongs on `RadioGroup`.
