# @bento/storybook-addon-helpers

Guide for working with the Storybook addon helpers package.

## Build/Test

Run tasks through Nx, scoped to `@bento/storybook-addon-helpers` (prefix with the package manager, e.g. `pnpm nx`; don't run these on other workspaces):

```sh
pnpm nx run @bento/storybook-addon-helpers:typecheck
pnpm nx run @bento/storybook-addon-helpers:lint
pnpm nx run @bento/storybook-addon-helpers:build
pnpm nx run @bento/storybook-addon-helpers:test
```
